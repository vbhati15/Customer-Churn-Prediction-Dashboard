# 📊 Customer Churn Prediction Dashboard  

A complete end-to-end machine learning project that predicts customer churn and generates insights using feature importance, classification metrics, and visual outputs.

This project is part of my analytics + consulting portfolio and demonstrates my ability to:
- Clean and analyze structured data  
- Train ML models (Logistic Regression, Random Forest)  
- Evaluate business-relevant metrics (accuracy, ROC AUC)  
- Generate actionable insights  
- Build fully reproducible pipelines  

## 🚀 Features
- Cleaned & encoded real-world style churn dataset  
- Logistic Regression & Random Forest models  
- ROC curve, feature importance, predictions CSV  
- Fully reproducible Python script  
- Outputs saved automatically  
- Ready to run with Conda or pip
